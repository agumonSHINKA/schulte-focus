# 舒爾特專注力訓練

Mobile-first Progressive Web App for Schulte grid focus training (舒爾特方格), plus an Android app with a home-screen widget.

## Play (Web / PWA)

Open: https://agumonshinka.github.io/schulte-focus/

Add to home screen from Safari (iOS) or Chrome (Android) for offline standalone play.

## Android app + widget

Sideload the APK from [Releases](https://github.com/agumonSHINKA/schulte-focus/releases) (`android-v1`).

- App name: **舒爾特專注力**
- Home-screen widget: streak, today's best, games today, **開始練習**
- Source: [`android/`](./android)

On Android 8+: Settings → allow install from the browser/file manager ("未知的應用程式").
